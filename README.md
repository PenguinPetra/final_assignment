# DICOM MPR Viewer

知能情報実験実習2　医用画像処理実験　最終課題

DICOM（および連続TIFF）を読み込み、**Axial / Coronal / Sagittal の3断面**を表示する自作ビューアです。
読み込んだ画像から**肺の3Dモデル（ボリュームレンダリング）**も表示できます。

- 言語: Python（画像表示は Qt の `QPainter` による自前描画）
- 主なライブラリ: PySide6（GUI）、pydicom（DICOM 読込み）、VTK（3D 表示）

---

## 1. 動作環境

| 項目 | 内容 |
|---|---|
| Python | **3.12 系を推奨**（3.12.3 で作成）。3.11 でも可。**3.13 以降は不可**（PySide6 6.7.2 / VTK 9.3.1 が未対応） |
| OS | Windows 10/11、macOS、Linux（画面表示ができる環境） |
| 必要パッケージ | `requirements.txt` に記載（バージョン固定済み） |

`requirements.txt` の内容:

```
numpy==1.26.4
scipy==1.13.1
pydicom==2.4.4
PySide6==6.7.2
vtk==9.3.1
pillow==10.4.0
```

## 2. インストールと起動

ターミナル（VS Code のターミナル可）で、このフォルダ（`viewer.py` がある場所）に移動して実行します。

### Windows（PowerShell）

```powershell
python --version                  # 3.11 または 3.12 であることを確認
python -m venv venv               # 仮想環境の作成
.\venv\Scripts\Activate.ps1       # 仮想環境の有効化（行頭に (venv) と出ればOK）
pip install -r requirements.txt   # パッケージのインストール
python viewer.py                  # 起動
```

- 「スクリプトの実行が無効」というエラーが出た場合は、次を実行してからやり直してください。
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
- コマンドプロンプトの場合は、有効化を `venv\Scripts\activate.bat` に置き換えてください。
- Python が複数入っている場合は、`py -3.12 -m venv venv` のようにバージョンを指定して作成してください。

### macOS / Linux

```bash
python3 --version
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python viewer.py
```

## 3. 評価用クイックスタート

1. 上記の手順で `python viewer.py` を実行する。
2. メニュー **ファイル → DICOM フォルダを開く…** で、DICOM 画像が入ったフォルダを選ぶ。
3. 3断面が表示される。スライダーを動かして、緑の線が連動することを確認する。
4. メニュー **3D → 現在の画像から肺を3D表示** で、肺の3Dモデルが開く。

※ DICOM データ・TIFF データはこのフォルダには含まれていません。評価用データを選択してください。

## 4. 画面と操作方法

### 4.1 画像の読み込み（ファイルメニュー）

| メニュー | 内容 |
|---|---|
| DICOM フォルダを開く…（`Ctrl+O`） | 選んだフォルダ内の DICOM をまとめて読込み（サブフォルダも探索） |
| DICOM ファイルを開く…（`Ctrl+Shift+O`） | DICOM ファイルを個別に複数選択して読込み |
| TIFF 画像（連続TIFF）を開く…（`Ctrl+T`） | 連続TIFF（例: 第5回の `hai.tif`）を読込み。読込み直後に画素間隔の設定画面が開く |
| 画素間隔(スライスサイズ)の設定… | X・Y（mm/px）と Z（スライス間隔 mm）を変更。画像の縦横比に反映される |
| 終了（`Ctrl+Q`） | アプリを終了（3D ウィンドウも自動で閉じる） |

### 4.2 3断面の表示

- 左から **Axial（体軸断）/ Coronal（冠状断）/ Sagittal（矢状断）** を表示します。
- 各画像上の **緑の線** は、他の2つの断面の位置を表します。
- 画像を **左クリック／ドラッグ** すると、その位置に合わせて他の2断面のスライスが移動します。

### 4.3 スライダーとボタン（各断面の下）

| 操作部 | 内容 |
|---|---|
| Slice | スライス位置（Axial = Z、Coronal = Y、Sagittal = X）。動かすと他の断面の緑線も連動する |
| WL | Window Level（ウィンドウレベル） |
| WW | Window Width（ウィンドウ幅） |
| WL/WW リセット | その断面の WL/WW を、読込み時の値に戻す |

WL / WW は断面ごとに独立して変更できます。

### 4.4 3D 表示（3D メニュー）

**3D → 現在の画像から肺を3D表示** を選ぶと、現在開いている画像から3Dモデルを作って別ウィンドウに表示します（画像の選択は不要）。

| 開いている画像 | 3D 表示の対象 |
|---|---|
| DICOM | HU 値から肺領域を簡易抽出して表示（HU < -400 の空気領域のうち、体外の空気を除いた上位2成分） |
| TIFF | 白い部分（画素値の最大・最小の中間値より大きい領域）を表示。第5回の肺マスク TIFF を想定 |

3D ウィンドウの操作:

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 拡大・縮小 |
| 中ドラッグ | 平行移動 |
| XY / YZ / ZX ボタン | 視点の切替（XY = 体軸断面の向き、YZ = 矢状断の向き、ZX = 冠状断（正面）の向き） |
| 上下(Z)反転 | 上下が逆に見える場合に切り替える |

- 形をきれいに見たい場合は、第5回の肺マスク（`hai.tif`）を TIFF として開いてから 3D 表示してください（DICOM からの抽出は簡易版です）。
- 3D 表示の形は画素間隔の設定に依存します。TIFF の場合は、DICOM と同じ値（特に Z のスライス間隔）を設定してください。

### 4.5 ヘルプ

**ヘルプ → 操作方法**（`F1`）で、操作説明を画面上に表示します。

## 5. 課題の観点との対応

| 観点 | 内容 | 実装 |
|---|---|---|
| 1 | スライス画像を表示する Viewer を自作 | `QPainter` による自前描画（`viewer.py` の `SliceView`） |
| 2 | ファイルメニューで DICOM を選択 | ファイルメニュー（フォルダ／ファイル選択） |
| 3 | Axial / Coronal / Sagittal を表示 | 3断面を並べて表示 |
| 4 | 他の2断面の位置を線で表示 | 各画像上の緑の線 |
| 5 | WL / WW とスライス位置をスライダーで変更 | 断面ごとのスライダー |
| 6 | 線がスライダーに連動 | スライダー操作で即時に線が移動 |
| 7 | 肺領域をボリュームレンダリングで 3D 表示 | 3D メニュー（VTK、`lung3d.py`） |

追加機能: 連続TIFF の読込み、画素間隔の設定、WL/WW リセットボタン、画像クリックによる位置移動、3D の視点切替ボタン、ヘルプ。

## 7. 実装の概要

- **DICOM 読込み**: `pydicom` で読込み、`ImagePositionPatient` / `ImageOrientationPatient` からスライス順を決定。`RescaleSlope` / `RescaleIntercept` で HU 値に変換し、(Z, Y, X) のボリュームにする。
- **TIFF 読込み**: `Pillow` でマルチページTIFFを (Z, Y, X) に読込み。WL/WW の初期値とスライダー範囲は画素値の範囲から決定。
- **断面表示**: ボリュームから各断面を切り出し、画素間隔から物理サイズの縦横比を保って表示（Coronal / Sagittal は頭側が上）。
- **WL / WW**: `(値 − (WL − WW/2)) / WW × 255` を 0〜255 にクリップして表示。
- **3D 表示**: 領域マスクを XY 方向に 1/2 に縮小してガウス平滑化し、不透明度・カラー伝達関数を設定して、VTK の `vtkFixedPointVolumeRayCastMapper`（CPU レイキャスト）で描画。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| `pip install` が失敗する | Python のバージョンを確認（3.11 / 3.12 が必要）。3.13 以降では入らない |
| 起動時に `ModuleNotFoundError` | 仮想環境が有効か確認（行頭に `(venv)`）。有効でなければ有効化して `pip install -r requirements.txt` をやり直す |
| DICOM が読み込めない | 画像が入ったフォルダを選んでいるか確認。画像でないファイルは自動的に無視される |
| 3D の形が縦に潰れて／伸びて見える | 「ファイル → 画素間隔(スライスサイズ)の設定…」で Z のスライス間隔を正しい値にする |
| 3D の上下が逆 | 3D ウィンドウの「上下(Z)反転」を切り替える |
| 3D 表示でエラーが出る | 3D 以外の機能は単体で動作する（`lung3d.py` は 3D メニュー選択時にのみ読み込まれる）。エラー文を確認し、グラフィックドライバを更新する |
| 3D の表示に時間がかかる | CPU で描画しているため、スライス枚数が多いと数秒かかる。しばらく待つ |

---

## 9. 注意事項

- DICOM データと TIFF データは本リポジトリに含まれていません。
- DICOM からの肺抽出は閾値と連結成分による簡易版です。
- 3D 表示は CPU レンダリングのため、環境によっては描画に時間がかかります。
